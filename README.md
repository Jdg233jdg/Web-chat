# Web-chat MVP Kickoff

This repository now includes an initial Blinkx Beat-style MVP prototype based on `BLINKX_BEAT_MVP.md`.

## What's included

- `index.html`: Lean-back homepage with a curated "Play Channel" experience
- `styles.css`: Core layout and visual styling
- `app.js`: Mock data, autoplay behavior, filtering, queue/save interactions
- `schema.sql`: Initial SQL schema for the MVP data model

## Run locally

```bash
python3 -m http.server 8000
```

Then open `http://localhost:8000`.

## Notes

This is intentionally a lightweight first implementation to begin product creation and validate UX direction before backend integration.
